# Courtly（仮）UIプロトタイプ

ウィンブルドンの品格 × 東京の社会人ライフスタイルのテニスコミュニティアプリ。モックデータで動作するUIのみ（認証・DB・決済なし）。

| 画面 | パス | 内容 |
|---|---|---|
| ホーム | `/` | プレー意欲登録、次の予定、横スクロール日付カレンダー、選択日のプレー希望者、イベント |
| プレー希望登録 | `/register` | 意欲（2択）、希望日・時間帯・地域（複数選択） |
| さがす | `/search` | キーワード検索、意欲・レベル・時間帯・地域で絞り込み |
| プレーヤー詳細 | `/players/[id]` | プロフィール、プレーしたい日、声かけ・返信のやりとり |
| イベント一覧 | `/events` | すべて／参加予定 |
| イベント詳細 | `/events/[id]` | 内容・持ち物・参加者、参加申込とキャンセル |
| お知らせ | `/notifications` | 声かけへの返信（未読バッジ連動） |
| マイページ | `/me` | プロフィール、プレー希望、声かけ・参加予定の一覧、デモデータのリセット |

すべてモックデータで動作し、操作内容はブラウザの localStorage に保存されます。声かけは送信の約5秒後に相手から承諾の返信が届く（モック）仕様です。初期状態に戻すにはマイページの「デモデータをリセット」を使います。

## 起動

```bash
npm install
npm run dev          # http://localhost:3000
npm run dev:lan      # 同一Wi-Fiのスマホから http://<PCのIP>:3000 でアクセス
```

技術：Next.js 15 (App Router) / TypeScript / Tailwind CSS / Lucide Icons
